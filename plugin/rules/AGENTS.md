When using `ae-control-mcp` tools:
- **No direct project edits or saves:** NEVER modify or save the user's `.aep` project directly (and never send `Ctrl+S`, `Ctrl+W`, `Ctrl+Q`, or `Alt+F4` to After Effects via `keyboard_hotkey`). Inspect After Effects read-only (`ae_get_project_info`, `ae_inspect_composition`, `ae_audit_project`, `ae_analyze_layout`, `ae_analyze_motion`, `ae_render_frame_preview`, `ae_render_annotated_preview`, `ae_render_contact_sheet`), then write standalone ES3 `.jsx` scripts using `ae_write_script` so the user can review and run them manually via **File -> Scripts -> Run Script File...**.
- **Script safety:** Every generated `.jsx` script MUST be ES3-compatible for After Effects 2020 (`var`, `function`, indexed `for` loops; NO `let`/`const`/`=>`/template literals/`Array.map`/`forEach`/`Object.keys`/trailing commas), wrapped in `app.beginUndoGroup("..."); try { ... } finally { app.endUndoGroup(); }`, and MUST NOT call `app.project.save()`. Prefer passing `include_stdlib=True` and `strict=True` to `ae_write_script` and fix any reported line issues before handing off.
- **Locale-independent matchNames:** Prefer `ADBE ...` matchNames over localized display names when adding or accessing effects/properties so scripts work in both English and Russian After Effects installations.
- **Cleanup:** When finished (or when requested), call `ae_cleanup_artifacts` to delete old screenshots, preview images, and temporary `ae_mcp_*`/`ae_frame_*` junk files. Never delete `.jsx` scripts or project files.
- **GUI safety:** Always take a fresh screenshot before clicking on coordinates, and pass `target_window` (e.g. `"After Effects"`) to `mouse_click` / `mouse_move` / `mouse_drag` / `mouse_scroll` / `keyboard_hotkey` so actions stay inside the intended application window. Never trigger destructive OS/file operations without explicit user confirmation.
- **Fail-safe:** Moving the mouse cursor to any screen corner triggers PyAutoGUI fail-safe and aborts the action immediately.
