When using `ae-control-mcp` tools:
- **No direct project edits or saves:** NEVER modify or save the user's `.aep` project directly (and never press `Ctrl+S` in After Effects via `keyboard_hotkey`). Inspect After Effects read-only (`ae_get_project_info`, `ae_analyze_layout`, `ae_render_frame_preview`), then write standalone ES3 `.jsx` scripts using `ae_write_script` so the user can review and apply them manually via **File -> Scripts -> Run Script File...**.
- **Script safety:** Every generated `.jsx` script MUST be ES3-compatible for After Effects 2020 (`var`, `function`, no `let`/`const`/`=>`/template literals), wrapped in `app.beginUndoGroup("..."); try { ... } finally { app.endUndoGroup(); }`, and MUST NOT call `app.project.save()`.
- **Cleanup:** When finished (or when requested), call `ae_cleanup_artifacts` to delete old screenshots, preview images, and temporary `ae_mcp_*`/`ae_frame_*` junk files. Never delete `.jsx` scripts or project files.
- **GUI safety:** Always take a fresh screenshot before clicking on coordinates, and pass `target_window` (e.g. `"After Effects"`) to `mouse_click` / `mouse_move` / `mouse_drag` so actions cannot click outside the intended application window. Never trigger destructive OS/file operations without explicit user confirmation.
- **Fail-safe:** Moving the mouse cursor to any screen corner triggers PyAutoGUI fail-safe and aborts the action immediately.
